# ENT101 GitHub Pages yükleme paketi

Bu klasörün İÇİNDEKİ dosya ve klasörleri GitHub repository'nizin kök dizinine yükleyin:

- index.html
- .nojekyll
- hafta1-2/  (klasörün tamamı)

## GitHub Pages ayarı
Repository > Settings > Pages
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

Yayın adresi:
https://KULLANICI-ADINIZ.github.io/REPOSITORY-ADI/

Hafta 1–2 doğrudan adresi:
https://KULLANICI-ADINIZ.github.io/REPOSITORY-ADI/hafta1-2/

Not:
- iPhone/Android/bilgisayarda normal web sayfası gibi açılır.
- İlk açılıştan sonra Hafta 1–2 sayfası çevrimdışı da kullanılabilir.
- iPhone'da Safari > Paylaş > Ana Ekrana Ekle ile uygulama gibi eklenebilir.
